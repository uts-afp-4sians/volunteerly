# Volunteerly Design Context

Volunteerly is a SwiftUI iOS application with three native root tabs: Search,
Bookmarks, and My Page. Root screens use a consistent mobile shell based on the
existing Search and Bookmarks layouts.

## Shared Root Layout

- `VolunteerlyHeader` at the top
- 20pt horizontal padding
- 16pt top padding
- 20pt vertical section spacing
- 24pt bottom padding
- `Theme.background` as the screen background
- Hidden navigation bar

## Accessibility

Follow iOS Human Interface Guidelines and WCAG 2.2 AA. Preserve Dynamic Type,
VoiceOver labels, native tab behavior, and minimum 44pt touch targets.

## Reference

The existing Search and Bookmarks screens are the source of truth for root-screen
alignment. My Page retains its profile content but uses the same outer shell.
